# Realtime Kanban

A kanban board that updates live for everyone viewing it. When one person moves a card, everyone else sees the change right away, with no refresh.

## Planned features

- Boards with customizable columns (To Do, In Progress, Done)
- Drag-and-drop cards
- Live sync across users
- Card details: title, description, assignee, due date
